About denr

  
Editor. Run runs the script or the R chunk; Ctrl/⌘ + Enter (or the green button below) runs the statement at the cursor and moves on. Suggestions appear after three letters; Tab accepts, Ctrl + Space asks for them.

  
Console. A real R session in this browser. Stop interrupts a long run and keeps your objects; readline() asks for an answer below. ?topic opens the Help tab.

  
Panes. Drag the handles to resize; each pane's ⋯ menu shows another panel, splits it, or closes it. Settings has themes, fonts, zoom and plot size.

  
Data. Tables open in Plank; View(df) opens a data frame and Send to R makes one from the rows and columns shown.

  
Files and settings stay on this device. After R has started once, denr works offline.
